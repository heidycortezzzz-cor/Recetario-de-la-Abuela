# RECETARIO DE LA ABUELA

> Guarda las recetas de la familia antes de que se pierdan, para quien cocina en casa.

## Qué hace

- Guarda una receta con nombre, ingredientes (con cantidad), pasos y foto.
- Convierte las porciones de una receta y recalcula cada ingrediente.
- Busca recetas por un ingrediente que haya en casa.
